## Where AgentDNS stands today
AgentDNS is a decentralized registry and discovery network for AI agents, mapping natural-language queries to discoverable, verifiable AI agents across a federated peer-to-peer mesh. It features a hybrid search engine combining BM25 keyword search and semantic vector search, along with a gossip protocol for mesh propagation and EigenTrust for reputation scoring. The current implementation includes a Go binary backed by PostgreSQL and Redis, supporting agent registration, discovery, and live Agent Cards. Key components include the Registry Store, Search Engine, Gossip Protocol, Peer Manager, and Agent Card Fetcher.
